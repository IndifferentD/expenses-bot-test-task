# Бэкенд

Go-код REST API для веб-панели и Telegram-бота, который обрабатывает запросы о тратах через LLM.

## Бинарники

- `cmd/api` — обслуживает HTTP API для пользователей и трат.
- `cmd/bot` — получает сообщения Telegram, передаёт их ассистенту и отвечает пользователям. Работает только с тратами автора сообщения.
- `cmd/seed-expenses` — создаёт 100 тестовых трат для существующих пользователей; если пользователей нет, ничего не добавляет.

Инструкции по запуску и настройке — в [корневом README](../README.md).
